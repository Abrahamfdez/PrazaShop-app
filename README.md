# PrazaShop

## Descripción
PrazaShop é unha aplicación móbil orientada a dar visibilidade ao comercio local. A aplicación permitirá que negocios locais publiquen os seus produtos frescos ou artesanais e que os clientes poidan consultalos e realizar compras desde o seu móbil.

Tamén permitirá crear compras recorrentes e ofrecer información sobre a duración das ofertas dos produtos (por exemplo: só hoxe, esta semana ou durante a tempada).

O obxectivo é conectar aos clientes cos negocios locais e fomentar o consumo de produtos de proximidade.

## Objetivos
- Desenvolver unha aplicación móbil multiplataforma.
- Permitir aos negocios locais publicar os seus produtos.
- Permitir aos clientes consultar e comprar produtos facilmente.
- Implementar un sistema de compras recorrentes.
- Crear un sistema de valoración e ranking dos negocios.
